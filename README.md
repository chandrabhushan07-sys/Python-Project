# Number Guessing Game

## Project Information
- **PS No.:** 91
- **Project Title:** Number Guessing Game
- **Language:** Python 3
- **Concepts:** Loops, Conditions, Functions, Random Module

## Problem Statement
Create a game in which the computer picks a random number between 1 and 100 and the player guesses it within limited attempts, receiving "Too high" or "Too low" hints.

## Features
1. Generates a random number between 1 and 100.
2. Gives the player 5 attempts.
3. Displays hints when the guess is too high or too low.
4. Validates invalid and out-of-range inputs.
5. Displays the number of attempts used.
6. Allows the player to play again.

## Requirements
- Python 3 installed on your computer.

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Run the following command:

```bash
python number_guessing_game.py
```
